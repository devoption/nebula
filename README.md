# Nebula

Nebula is an AI-infused software factory for Laravel application and package development.

## Installation

Before you begin, make sure you have the following installed:

| Dependency | Version |
|:-----------|:-------:|
| PHP        | v8.3+   |
| Composer   | v2.9+   |

```sh
composer create-project devoption/nebula
```
